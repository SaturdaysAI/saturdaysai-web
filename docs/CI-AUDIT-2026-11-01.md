## Correcciones

- Las referencias rotas de ambos artículos se repararon en `5ea70b4`. Ese [despliegue](https://github.com/SaturdaysAI/saturdaysai-web/actions/runs/41356136499) llegó correctamente a producción.
- Los borradores y los artículos con fecha futura se excluyen de la preparación de imágenes. La misma regla se usa en la validación previa y está cubierta por pruebas de regresión.
- Los contadores, tiempos de lectura, etiquetas de temporada/episodio y mensajes de fecha generados tienen plantillas bilingües. Las fechas de elementos `time` se formatean directamente con `Intl` y no generan segmentos nuevos. Se conservan las traducciones editoriales existentes.
- `npm run validate:content` comprueba contenido, fechas e imágenes antes de generar las imágenes y compilar la web. Informa del archivo que causa cada error y comprueba mayúsculas/minúsculas como en Linux.
- El run guarda un resumen en español y un artefacto `publication-diagnostics` durante 14 días, incluso cuando la validación falla. La cobertura de traducciones indica texto, ruta e idioma pendientes. La falta de un informe auxiliar no permite saltarse una validación fallida ni bloquea por sí sola una versión válida.
- Se fija Ubuntu 24.04 para evitar cambios imprevistos de `ubuntu-latest`, se añaden límites de ejecución y se actualizan las acciones a versiones con soporte de Node 24. Se mantienen los permisos de despliegue y el acceso de solo lectura al contenido; checkout no persiste credenciales.

La actualización de las acciones sigue las publicaciones oficiales de [checkout](https://github.com/actions/checkout/releases), [setup-node](https://github.com/actions/setup-node/releases), [upload-pages-artifact](https://github.com/actions/upload-pages-artifact/releases) y [deploy-pages](https://github.com/actions/deploy-pages/releases).
