# Brand implementation

Verified against the identity PDF supplied by the owner, the later brand presentation, the communication manual, and the logo folders on 24 October 2026.

## Identity

| Element      | Rule                                                                           |
| ------------ | ------------------------------------------------------------------------------ |
| Name         | Saturdays.AI; local programme name AI Saturdays                                |
| Typeface     | Montserrat, self-hosted variable font                                          |
| Sandy orange | `#FF9D5A`                                                                      |
| Navy         | `#151E3F`                                                                      |
| Blue         | `#0B6099`                                                                      |
| White        | `#FFFFFF`                                                                      |
| Logo         | Original artwork, preserved proportions and surrounding whitespace             |
| Voice        | Friendly, inclusive, clear and grounded in learning together and social impact |

Orange is an accent and button background with navy text. Blue is used for readable text links. Pale tints support the hierarchy. Motion is restrained and disabled by the reader's reduced-motion preference.

The primary logo is an optimized derivative of the original horizontal orange PNG. The network artwork is supplied brand artwork, not a newly drawn mark. Sixteen available local city logos are included on their city pages. The remaining city profiles retain the global identity. The social sharing card uses the same original logo and official palette.
