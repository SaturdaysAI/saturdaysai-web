## Temario:

### Neighborhood-Based  
Methods

![](/media/0ccc5a30fdae3a44.webp)

Iniciaremos con conceptos básicos con Machine Learning. Después empezaremos con Machine Learning supervisado viendo los primeros métodos de Machine Learning: K Nearest Neighbors, K-D trees. También revisaremos sobre el caso Netflix.

### Tree-Based  
Methods

![](/media/93180047c03b2590.webp)

Continuaremos con los distintos métodos basados en árboles de decisión: Decision Trees, Regression Trees, Classification Trees. Revisaremos  CHAID, CART.

### Ensemble  
Methods

![](/media/3800474056f3a217.webp)

Usaremos Ensemble Methods para combinar modelos y producir mejores resultados. Revisaremos Boosting(Adaboost, Stochastic Gradient Boosting), Bagging(Random Forest).

### Linear and Non-linear  
Methods

![](/media/f218ee818a969a4b.webp)

Culminaremos la etapa de Machine Learning supervisado revisando Linear Regression, Logistic Regression, Shrinkage Methods y Support Vector Machines

### Dimensionality  
Reduction​

![](/media/1b8518915ad37d08.webp)

Iniciaremos la etapa de Machine Learning no supervisado con la reducción de dimensionalidad. Veremos Principal Component Analysis, Linear Discriminant Analysis y t-SNE.

### Clustering  
Methods

![](/media/b32fd93e8f26ed51.webp)

Concretaremos la etapa de Machine Learning no supervisado con los métodos de clustering. Veremos K-Means Clustering, Hierarchical Clustering, DBSCAN.

### Advanced  
Topics

![](/media/9b778001e1fd19f8.webp)

Revisaremos la introducción a Deep Learning y al Procesamiento del Lenguaje Natural.

### Cloud for  
Machine Learning

![](/media/17c5969bb640dc4d.webp)

Fundamentos de cloud y uso de Amazon Web Services para el deploy de modelos de Machine Learning.

### Proyecto de  
Inteligencia Artificial

![](/media/31d564a82e023a43.webp)

En este modulo impartiremos temas sobre desarrollo de proyectos. Los alumnos desarrollarán un proyecto aplicando lo aprendido en el programa para presentarlo en el Demo Day.
